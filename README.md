# APBD – Ćwiczenia 1: Git i GitHub

Prosta aplikacja konsolowa w C# (.NET), która dla tablicy liczb wypisuje
powitanie oraz statystyki: sumę, średnią, liczbę elementów i maksimum.
Repozytorium pokazuje scenariusze scalania gałęzi: fast-forward,
three-way merge bez konfliktu oraz merge z konfliktem.

## Uruchomienie

Wymagany .NET SDK.

```bash
git clone https://github.com/s30674-max/apbd-cw1-git.git
cd apbd-cw1-git
dotnet run
```
